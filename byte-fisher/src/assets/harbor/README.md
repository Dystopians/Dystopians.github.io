# Neon Harbor Art Assets

Created with the built-in imagegen tool. Original PNGs and optimized runtime assets are kept together in this directory. No external image URL is required at runtime.

## Asset Preparation

Run `pnpm assets:harbor` to rebuild the PNG cutouts and lossless WebP backgrounds. Sprite alpha is retained. The fish atlas uses inspected row boundaries at 0, 330, 650 and 1024 pixels, not guessed equal rows. Solid bounds are checked against cell edges before saving. Runtime images preserve aspect ratio.

The original static character source crop is x=282, y=107, width=469, height=1333. Its 68x192 fallback sprite has a normalized hand anchor at (0.91, 0.408) and a bottom-center foot anchor. Active gameplay now uses `angler-actions.png`, a 12-pose full-body atlas with calibrated hand anchors and a common foot baseline. See [ANGLER_ACTIONS.md](ANGLER_ACTIONS.md) for the new source, exact prompt and reproducible preparation. The fishing rod follows the active hand; its endpoint is also the line attachment. Item icons are for the inventory and are never pasted over the character.
